# Dog Dash

A single-file HTML canvas runner game. Open `index.html` in a browser, or serve it with GitHub Pages.

- 13 levels (Classic Meadow up to Crystal Cave) plus the gold **Chaos in the Mix** level (50 bones per run)
- Difficulty climbs level by level
- Skins are bought with bones earned by playing (no real money)
- Music is synthesized in the browser; some levels use small embedded audio loops, so the file is large (~2.4 MB)

## Working on it

Because of the embedded audio, don't open the whole file at once. Search it (`grep -n`) and read only the line ranges you need.
